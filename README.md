# Glory — сайт про рыцарей

Учебный проект на React + Vite. Тёмная эстетика рыцарства: мечи, доспехи, кодекс, хроника.

## Фишка — «Удар мечом»

Слово GLORY нарисовано на canvas как полированная сталь. Если резко взмахнуть мышкой
(или пальцем) сквозь него — слово разрубается по линии взмаха: куски разлетаются,
срез раскаляется, летят искры, экран вздрагивает. Через пару секунд сталь сама
сваривается обратно. После загрузки сайт делает один показательный удар.
Разрубить можно любой элемент с атрибутом `data-slice` (на сайте их два — в начале и в подвале).

Код фишки — `src/components/SwordSlash.jsx`.

## Что ещё есть

- **Арсенал** — 7 мечей, нарисованных в SVG в одном масштабе, листаются вбок (`Arsenal.jsx`, `Sword.jsx`)
- **Доспех** — точки на фото рыцаря с описанием частей доспеха и 4 шлема (`Armor.jsx`, `Helmet.jsx`)
- Кодекс, галерея, хроника, цитата с огромным мечом

## Запуск

```
npm install
npm run dev
```

Открыть http://localhost:5173

## Структура

- `src/App.jsx` — собирает страницу из секций
- `src/components/` — секции и компоненты
- `src/data.js` — все тексты и параметры мечей
- `src/App.css` — все стили
- `public/img/` — картинки

Подробный разбор всего кода, строка за строкой, лежит в файле `Glory — разбор кода.docx`.
